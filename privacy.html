Data Transparency

Privacy & Ethics

Carbotrack is a student project — but it handles real account data. This page explains exactly what we collect, where it lives, and how to remove it.

No real email needed

Your sign-in email is generated as username@carbotrack.local — a placeholder. We never collect a real address.

No tracking pixels

No Google Analytics, Facebook Pixel, or third-party advertising. Only anonymous, aggregated usage counters.

You can delete everything

Sign-out wipes local data instantly. Server data deletion is available on request — details below.

Row-Level Security

Database policies prevent any user from reading, editing, or deleting another user's private data. Enforced at the Postgres layer.

What we store

Everything Carbotrack keeps is listed below. Nothing is hidden.

Data Where Why Visibility
Username Supabase profiles Sign-in identifier, displayed in leaderboard Public (leaderboard)
Full name Supabase profiles Appears on certificates and leaderboard Public (leaderboard, certificates)
Generated login email Supabase auth.users username@carbotrack.local — placeholder only Private (server only)
Hashed password Supabase auth.users Authentication — never stored in plain text Private (server only)
Footprint calculations Supabase carbon_results History, trends, leaderboard rank Total value is public; breakdown is private
7-day challenge progress Supabase challenge_progress Sync across devices Private (you only)
Anonymous session ID Browser localStorage + visitor_sessions Debounce homepage counters (1 visit / day) Random UUID, not linked to identity
Theme preference Browser localStorage only Remember light / dark mode Never sent to server

Where your data lives

All account data is stored in Supabase (built on PostgreSQL), a managed backend platform. Data is encrypted in transit (HTTPS/TLS) and at rest. The Supabase project used by Carbotrack is hosted on a shared infrastructure tier; the specific region depends on the project owner's Supabase plan.

The frontend is a static site with no server — every page you see is served as HTML/CSS/JS and makes direct HTTPS calls to Supabase for data. No intermediate server ever sees your password in plain text.

What we deliberately do not collect

  • Real email address — a generated placeholder is used instead
  • Phone number
  • Real name unless you type it into the "Full Name" field
  • GPS or IP-based location
  • Device fingerprint, browser list, or OS version
  • Cookies for advertising or cross-site tracking
  • Photos, files, or uploads of any kind
  • Payment information (the app is free)

Certificates & shared links

When you download a certificate, all of its data (name, tier, footprint, date, certificate ID) is encoded locally into the PNG/PDF. Nothing additional is transmitted.

When you use the "Share Certificate" button, a URL with an encoded payload is generated (certificate.html#s=…). This payload is base64-url encoded JSON and contains only the visible certificate information. It is not cryptographically signed — that means anyone can craft a share URL that produces a valid-looking certificate. Treat shared certificates as self-asserted, not verified.

Leaderboard disclosure

If you are signed in and submit a calculation, your full name and username become visible to anyone who opens the leaderboard. Your total annual footprint and eco score are also public. Your detailed category breakdown (transport / energy / diet / water / waste / lifestyle) stays private — only the aggregated total is shown.

If you prefer privacy, you can use the calculator without signing in — results will still work, but they won't be saved to the leaderboard or synced across devices.

How to delete your data

Local data (instant): Sign out from the header menu, or click Sign Out on your profile page. This immediately clears results, inputs, challenge progress, and settings stored in your browser's localStorage. No traces remain on your device.

Server data (on request): Your account, calculations, and challenge progress are stored in Supabase. Full deletion is available — email the project contact listed below with your username and we will delete your row from auth.users (cascades to profiles, carbon_results, and challenge_progress). Deletion completes within 7 days.

Because this is a CHE110 academic project, the server may be decommissioned at the end of the course. All data will be deleted at that time without further notice.

Third-party services

Carbotrack loads the following external resources — each makes a request to the vendor's CDN when the page loads. None of them receive your account data.

  • Supabase — authentication, database, real-time (received account data, encrypted)
  • jsDelivr / cdnjs — Supabase JS, Chart.js, html2canvas, jsPDF, QRCode, Font Awesome
  • Google Fonts — Inter, Poppins, Playfair Display, Cormorant Garamond
  • Tailwind CDN — utility CSS framework

Each CDN receives the standard HTTP metadata (your IP, browser, referring page) necessary to serve the file. Carbotrack has no control over their logging policies.

Academic Context

This privacy disclosure is itself part of the CHE110 continuous assessment — environmental education includes teaching responsible data stewardship. The project is graded on transparency, so this page is intentionally thorough.

Questions, correction requests, or data-deletion requests: contact the team via the Academic Info page.
