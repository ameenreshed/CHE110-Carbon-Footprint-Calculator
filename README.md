# CarbonTrace: Carbon Footprint Calculator

CHE 110 Environmental Studies, CA1 group project (Group 1, Section K4P26HB), Lovely Professional University.

Estimates a person's yearly CO2 footprint from travel, flights, electricity, LPG, diet and waste, shows a breakdown, compares it with India, world and Paris-aligned levels, and suggests where to cut first.

## Files
- `index.html`, `calculator.html`, `learn.html`, `about.html`: pages
- `style.css`: styles (light and dark mode, responsive)
- `script.js`: calculation, charts, saved results (localStorage), mobile menu

## Run
Open `index.html` in a browser. No installation needed.

## Publish on GitHub Pages
Push all files to a repository, then Settings > Pages > Deploy from branch `main`, folder `/ (root)`.

## Method
Annual emissions = activity x emission factor, summed across categories. Factors are rounded approximations listed in `about.html` and at the top of `script.js`; verify with CEA/IPCC sources before citing.
