Tools, Technologies & Libraries
Complete technology stack used to build Carbotrack — every dependency and API traced from the source code.
1Architecture at a Glance
🎨

Presentation

10 static HTML pages · hand-authored CSS · Tailwind CDN utility layer · Chart.js visualizations

⚙️

Client Logic

Vanilla JavaScript (18 modules) · no bundler · no framework · ES2020+ · pure calculation engine

☁️

Backend

Supabase (PostgreSQL + Auth + Realtime) · row-level security · security-definer RPC functions

Deployment model: Fully static frontend (no build step, no node_modules) talking directly to Supabase over HTTPS. Deployable to any static host — GitHub Pages, Netlify, Vercel, Cloudflare Pages, or a simple python -m http.server.

5JavaScript Modules

18 independent modules loaded in a fixed order. No dependencies between them except through window.CT_* globals.

Core

  • config.js — emission factors, benchmarks, palette
  • storage.js — safe persistence + URL-hash transport
  • engine.js — pure calculation engine
  • app.js — mobile drawer, toasts, nav
  • theme.js — dark mode + back-to-top

Calculator & Results

  • calculator.js — multi-step form controller
  • charts.js — Chart.js wrappers
  • results.js — dashboard render + PDF export

Auth & Persistence

  • supabase-config.js — credentials
  • supabase-client.js — client init
  • supabase-auth.js — sign-up/sign-in
  • supabase-leaderboard.js — RPC wrappers
  • supabase-challenge.js — challenge sync
  • auth.js — UI + gated pages

Features

  • challenge.js — 7-day tracker
  • challenge-notifications.js — reminders
  • certificate.js — 5 cert variants + share
  • leaderboard.js — realtime ranking
  • profile.js — history + trend chart
  • visit-counter.js, stats.js — analytics
