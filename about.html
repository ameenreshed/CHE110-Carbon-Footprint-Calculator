About the project

CarbonTrace is a prototype built for CHE 110 Environmental Studies (CA1). It estimates an individual's yearly carbon footprint from lifestyle choices and suggests where to reduce emissions.

Method and emission factors

Yearly emissions = activity amount × emission factor, summed over five categories. Factors are rounded approximations; verify them against sources such as CEA and IPCC before citing.

Petrol / diesel / CNG / electric car0.17 / 0.15 / 0.12 / 0.08 kg CO₂ per km
Two-wheeler0.05 kg CO₂ per km
Bus or train0.04 kg CO₂ per km
Return flight (average)250 kg CO₂ each
Grid electricity0.71 kg CO₂ per kWh
LPG cylinder (14.2 kg)42.5 kg CO₂ each
Diet (veg / mixed / non-veg)1000 / 1500 / 1900 kg per year
Household waste0.45 kg CO₂ per kg
Tree absorption (for the tree equivalent)about 21 kg CO₂ per year

Technologies

HTML for structure, CSS for styling, and vanilla JavaScript for calculation, charts and saving results in the browser (localStorage). No frameworks or servers needed.
