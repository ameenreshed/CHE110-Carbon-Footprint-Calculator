CHE110 — Environmental Studies Project

Topic 1: Carbon Footprint Calculator — a working web prototype demonstrating software engineering applied to climate awareness.

Computer Science & Engineering Demonstration

Course: CHE110 — Environmental Studies

This prototype addresses Topic 1: Carbon Footprint Calculator. It exemplifies the practical application of software engineering, dynamic mathematical modelling, and interactive visualisation toward climate action and public awareness.

Component: Continuous Assessment 1 (CA1) • Deliverables: Web Prototype, Demo Video, Social Dissemination, Handwritten Report
Team Submission Specs
  • Group 1 — Section CSE
  • Codebase hosted on GitHub
  • Transparent calculation factors
  • Fully responsive mobile UI
  • Modular HTML / CSS / JS separation
  • Supabase-backed leaderboard & auth
View Repository Codebase

Technical Implementation

Built as a static, dependency-light multi-page web application. Styling uses a Tailwind utility layer over a hand-authored design-token system. All calculation logic lives in a pure, testable engine module with no DOM coupling.

  • • config.js — emission factors & benchmarks
  • • engine.js — pure calculation functions
  • • storage.js — safe persistence with memory fallback
  • • charts.js — Chart.js donut & bar wrappers
  • • supabase-auth.js — email/password authentication
  • • supabase-leaderboard.js — global rankings
  • • challenge-notifications.js — daily reminder system
  • • theme.js — dark/light mode controller
