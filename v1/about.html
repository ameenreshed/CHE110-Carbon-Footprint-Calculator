About the project

CarbonTrace is a CHE 110 Environmental Studies (CA1) prototype that estimates yearly carbon footprints and suggests where to cut.

Method

Emission factors

Yearly emissions = activity amount × emission factor, summed over five categories. Factors are rounded approximations; verify against sources such as CEA and IPCC before citing.

Petrol / diesel / CNG / electric car0.17 / 0.15 / 0.12 / 0.08 kg CO₂ per km
Two-wheeler0.05 kg CO₂ per km
Bus or train0.04 kg CO₂ per km
Return flight (average)250 kg CO₂ each
Grid electricity0.71 kg CO₂ per kWh
LPG cylinder (14.2 kg)42.5 kg CO₂ each
Diet (veg / mixed / non-veg)1000 / 1500 / 1900 kg per year
Household waste0.45 kg CO₂ per kg
Tree absorptionabout 21 kg CO₂ per year
Tech

Technologies

HTML for structure, CSS for styling and theming, and vanilla JavaScript for calculation, canvas charts and saved data in the browser (localStorage). Icons by Font Awesome and type by Inter. No frameworks or servers needed.
