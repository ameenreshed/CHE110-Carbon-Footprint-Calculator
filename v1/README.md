# CarbonTrace: Carbon Footprint Calculator

CHE 110 Environmental Studies, CA1 group project (Group 1, Section K4P26HB), Lovely Professional University.

## Files
- `index.html`, `calculator.html`, `learn.html`, `quiz.html`, `tracker.html`, `about.html`: pages
- `style.css`: styles (light and dark themes, responsive, print)
- `script.js`: calculation, canvas charts, planner, quiz, tracker, theme, saved data (localStorage)

## Run
Open `index.html` in a browser. No installation needed.

## Features
Modern clean UI with Font Awesome icons, Inter font, segmented controls and styled sliders. Live calculator with household split, eco grade A to E, doughnut chart, comparison bar chart, 10-year projection chart, saved-results trend chart, reduction planner with pledges, tree equivalent, share links (WhatsApp, X, LinkedIn, Facebook, Telegram), copy and Web Share, CSV export, print to PDF, eco quiz with badges, social media tracker for the report table, and dark/light theme.

## Publish on GitHub Pages
Push all files to a repository, then Settings > Pages > Deploy from branch `main`, folder `/ (root)`.

## Method
Annual emissions = activity x emission factor, summed across categories. Factors are rounded approximations listed in `about.html` and at the top of `script.js`; verify with CEA/IPCC sources before citing.
